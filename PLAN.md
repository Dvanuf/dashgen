# PLAN.md — Интеграция конвейера SUNLIGHT в Dashgen

**Статус: Утверждён** (утверждён владельцем через approval плана в ZCode, 2026-11-15). Ветка `feature/sunlight-pack`, коммит+push после каждого проверенного шага.

## Контекст

Dashgen собирает дашборды QSEoW из Excel с ИИ (спека v1 → builder → verify). Проблемы на сервере dc3-qliks-ap-03: `doReload` прямой сессии 4747 блокирован платформой (диагностика в sunlight-qlik-theme/PLAN.md, этап 5.4) — перезагрузка только через QRS-задачу; нет бренда SUNLIGHT; verify без условий по элементам; `build()` удаляет приложение при пересборке — ручные правки теряются.

Источник наработок: sunlight-qlik-theme/app-template (QRS-reload, verify-all с условиями по 30 элементам, reconcile, грабли KNOWN-ISSUES, палитра/расширения). Сам sunlight-проект не изменяется.

## Алгоритм работы с приложением (реализуемый сценарий)

1. **Данные** — как сейчас: Excel/inline/QVD → профиль (privacy) → спека.
2. **Выбор шаблона макета** — каталог макетов с зонами (фильтры → KPI → графики → детализация); варианты: «Обзор», «Детализация», «Компакт».
3. **ИИ формирует дашборд** — модель заполняет слоты выбранного макета мерами/измерениями из профиля; спека → сборка → QRS-reload → verify-all.
4. **Режим правок** — как сейчас: редактор раскладки drag+resize, замена мер, словесные правки; плюс правки напрямую в Qlik-клиенте или attach-режимом.
5. **Фиксация правок** — правки закрепляются: (а) из UI → spec.json с пометкой `fixed` (ИИ и пересборка не трогают); (б) из Qlik-клиента — команда «Зафиксировать с приложения» (снятие состояния → merge в spec); (в) пересборка в attach-режиме обновляет только нефиксированное.

## Ограничения и решения (журнал)

- 2026-11-15. Разведка: Dashgen 0.9.0 (Electron 45, enigma.js 12.612.0, ajv, xlsx, SheetJS), сервер тот же; QRS-клиент request() готов, нет reload/экспорта; verify однопроходный; builder удаляет приложение; ИИ-контур изолирован (privacy) — интеграция после валидатора.

- 2026-11-15. doReload блокирован сервером → QRS-задача обязательна; задача одноразовая (DELETE после выполнения); скрипт должен быть сохранён (doSave) до запуска задачи.
